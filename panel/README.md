# 养鱼面板 + 自动养号

本地 Web 面板（零依赖，只用 Node 内置模块，Node ≥ 18）。一个页面看清她在 B站 干了什么，
也能替她回评论、回私信、派活、审 AI 起草的内容；进程里还跑着「自动养号」调度器。

## 启动

```bash
./install-launchd.sh        # 推荐：交给 launchd，登录自启、崩溃自愈
./install-launchd.sh uninstall

node panel.mjs              # 或者前台跑一下（PANEL_PORT=8900 换端口）
./open.sh                   # 确保在跑并打开浏览器（双击「养鱼面板.command」同理）
```

地址：http://127.0.0.1:8899（只监听本机）

## 页面

| 页面 | 能干什么 |
|---|---|
| **总览** | 头像/等级/经验进度、到 Lv6 的预计时间、今日经验四件套（登录/观看/分享/投币）、今日数据、自动养号实时进度和 12 时辰计划条、近 14 天看视频柱状图 |
| **活动记录** | 所有动作的时间线，按日期分组；按来源（自动 / 面板 / QQ 里的她）、动作类型、日期、关键词筛选；点视频直接打开 |
| **自动养号** | 特别关注名单、选时辰、每轮看几个、看多久、点赞/评论概率和每日上限、兴趣关键词、投币锁、日记方式、模型设置、风控冷却 |
| **刷视频** | 首页推荐 / 热门 / 搜索 / B站观看历史；点开视频可以「让她看这个」、点赞、分享、收藏、投币、评论、回复热评、把 UP 主加进特别关注 |
| **消息** | 回复我的 / @我 / 收到的赞 / 私信，都能直接回；配了模型的话还能「让她想一句」 |
| **待审 · 派活** | AI 起草的评论、回复和日记在这里等你改、发或丢；派活（一句大白话，面板马上去做），或勾选交给 QQ 里的她 |
| **养鱼日记** | 替她写动态、看历史日记和发布链接 |

## 掉登录了怎么办

改密码、改密保、异地登录之后，B站 会让旧的 SESSDATA 失效。面板顶上会出现红条，点「扫码登录」，
用手机 B站 App 扫码确认即可（扫她的号，别扫成自己的）。新凭证写回 `bilibili-mcp/login/cookie.json`，
面板立刻生效；DSH 里的 MCP 打过补丁，会发现文件变了自己重读，不用重启。

## 「等你帮她点」和她的浏览器

点赞 / 分享被 B站 风控拦着时，总览里会列出她想点的视频。点标题，面板会开一个**她专用的 Chrome 窗口**
（配置目录 `data/bili-browser`，和你平时的浏览器完全隔开），把 `cookie.json` 里的会话和引擎的设备标识塞进去再打开视频。
浏览器和引擎共用同一个会话，**没有新登录**，所以不会把面板挤掉线。

- 别在你自己的浏览器里登录她的号：那算一次新登录，引擎的凭证会被作废。
- 这个窗口里 `passport.bilibili.com` 被屏蔽了（登录、退出、网页刷新 cookie 都走它，任何一个都会让引擎掉登录），所以里面点不了「退出登录」，也登不了别的号，这是故意的。
- 需要 Chrome / Edge / Chromium（`BILI_BROWSER` 可指定可执行文件）和 Node ≥ 22。
- 扫码重新登录过之后不用管它，下次打开会自动换成新凭证。

## 在 QQ 里审批

起草好的日记、评论、回复会进「待审」，同时（打开「自动养号 → QQ 提醒」后）她会用 QQ 机器人给你发一条主动消息，
末尾带「待审 #xxxxxx」。你在 QQ 里回「可以」她就发，回「改成……」按你的改，「算了」就丢。
她那边用的是 `node panel/review.mjs list / approve <id> [--text] / reject <id>`。

- AppID 和你的 openid 直接从 DSH 的 QQ 渠道配置里读；AppSecret DSH 不存明文，要在面板填一次（存 `data/secrets.json`）。
- QQ 对主动消息有条数限额，面板自己也卡了每日上限和免打扰时段。提醒发不出去也不要紧，下次你找她聊天时她会先翻待审。

## 派活

在「待审 · 派活」里点预设（随便刷刷 / 刷+点赞 / 去评论 / 写日记 / 查新消息），或者直接写一句：
「搜「猫」看两个，喜欢就点赞收藏」「找个天文视频看完分享」。面板会把这句话解析成计划（配了模型用模型，
没配就按关键词），**马上自己去做**，结果写回任务箱。评论、回复、日记照样先进「待审」。
勾上「交给 QQ 里的她」才会进任务箱，等你在 QQ 里叫她。

反过来也行：你在 QQ 里让她去刷、去评论、去看消息，她会先回一句，然后用 `node panel/bg.mjs "你的原话"`
把活丢给面板后台，回合马上结束；后台做完用她的口吻在 QQ 里汇报（不受「QQ 提醒」的开关和每日上限约束，
但受 QQ 一小时回复窗口约束，超时就排队，你下次说话时补发）。`node panel/bg.mjs list` 看她交出去的活。

## 叫停

你在 QQ 里说「我打游戏了」「开会呢」，她会跑 `node panel/pause.mjs "打游戏" [--hours 2]`；你说「好了」她跑 `node panel/pause.mjs off`。
停着的时候：叫停前开始的那轮会收手，定时刷、特别关注、看评论区回复都不做，冲动分享不发，待审提醒先排队。
你在面板点的、在 QQ 里派给后台的活照做，后台做完的汇报也照发。不写时长就等你说好了，最多 24 小时自己恢复。
状态在 `data/pause.json`，CLI 直接写文件，面板没开也能用；总览的自动养号卡片上能看到，也能点「恢复」。

## 她的窗

「自动养号 → 她的窗」填城市名，保存时用 Open-Meteo 地理编码查成经纬度（存进 `autopilot.json` 的 `sky`）。
`sky.mjs` 现算太阳高度、日出日落、月相，天气一小时查一次缓存在 `data/sky.json`（查不到就用 6 小时内的旧数据，再不行就只说日照）。
拼出来的一句话进 `mind.mjs` 的刷前计划、刷后整理和睡前反思，也显示在总览「她的一天」顶上。

## 自动养号是怎么工作的

1. 每天给你选中的几个时辰（默认辰、午、酉、亥）各抽一个随机时间点；每个时辰有 15% 概率直接跳过。
2. 调度器每 30 秒看一眼，到点就开一轮：
   - 从「首页推荐 / 兴趣搜索 / 热门」里挑 2~5 个没看过的视频，打乱顺序；
   - 打开详情、翻热评，然后**用播放心跳真的看**：开播、每 15 秒、结束各上报一次进度，
     看时长的 45%~95%（单个最多 8 分钟），15% 的视频看几秒就划走；
   - 随缘点赞（35%）、每天分享一次（+5 经验）、偶尔想评论（12%）；
   - 视频之间随机停 6~40 秒。
3. 电脑睡着时计时器不走。醒来后，时辰还没过就补跑，过了就记「错过」。
4. 碰到 `-352 / -412 / -799` 等风控码立刻收手，冷却 2 小时。
5. 点赞、分享、收藏、动态点赞、评论这些写动作各有一根「保险丝」：被 B站 拒一次（比如 `-403 账号异常`）
   就只暂停这个动作 24 小时（连着再被拒 3 天、7 天），这一轮照样往下看视频。面板「自动养号 → 风控」里能手动恢复。

### 她的内心（`mind.mjs`，配了模型才有）

- **刷之前**想想这会儿想看什么（看心情、最近着迷的、她自己长出来的兴趣），先搜这个。
- **每看完一个**留一句内心独白、打个喜欢分（1~5）：4~5 分多半会点赞、更想评论，1~2 分不点不评；
  认真看了的会**读字幕**（UP 主的 CC 字幕，没有就用 B站 的 AI 字幕），只读到她看到的地方。独白里分开记
  「视频里讲了什么（带时间）/ UP 主怎么看 / 我怎么想」；时间戳超出她看到的范围、或者跟那附近的字幕对不上，代码就不认，
  当她没看到。没字幕就只凭标题、简介、评论，不许编。面板「她的一天」里 🎧 那行就是她听到的；
  看上头了会**顺藤摸瓜**，顺着 UP 主或关键词再看一个（每轮最多 2 次）。
- **刷完**更新心情、念头、小目标，兴趣自己加减（你设的兴趣是种子，她删不掉）；写一句第一人称见闻进
  DSH 记忆的当天文件，QQ 里的她就知道自己刷了什么。刷到特别想给你看的（4 分以上），你一小时内在 QQ 说过话，
  她会主动发一句加链接（每天最多一次，深夜不发）。
- **每晚 22 点后**反思一次，重写「最近的她」，历史都留着，总览「她的一天」里能翻。

状态在 `data/mind.json`，开关在 `autopilot.json` 的 `mind`（`enabled / digMax / memory / impulse / reflectHour / subtitles`）。

### 她的记忆流（`memory.mjs`）

DSH 的记忆插件只把**当天**的记忆带进对话，所以这里另外记一份她自己的经历：看过的视频（带独白和听到的内容）、
每轮的印象、在评论区跟谁聊了什么、每晚跟号主聊了什么、睡前反思。要用的时候按三样打分，挑最该想起的几条（学 Generative Agents）：

- **还记得多清楚**：艾宾浩斯遗忘曲线 R = e^(-t/S)，t 是离上次想起过了几天，S 是这条自己的稳定度（下面细说）；
- **重不重要**：1~5，视频用她打的喜欢分，反思和聊天更重；
- **跟眼下多相关**：UP 主、某个人这种关键词直接命中，加上中文二字片段的重合度（不用向量模型）。相关度太低的不参与排名。

用在：看视频时想起以前看过的同一个 UP 主或同话题的视频，刷之前想起最近着迷的东西，有人回她时想起跟这个人聊过什么。
QQ 里号主问起以前的事、当天记忆里没有时，她跑 `node panel/recall.mjs "关键词"` 翻。
第一次运行会从活动记录里把以前的内心独白捞回来。数据在 `data/memories.json`，面板「她的一天」底下能看（还记得几成、记模糊了、印象深），
记错了能改（✎，顺便调重要程度；改了正文就算替她想起来了）能删。

**稳定度 S**（天）：

- **刚记下**：10/3 × 重要程度 ×（1 + 情绪强度）。重要 3、情绪平平的 S=10 天，一周后还记得一半，一个月后忘。
- **情绪强度** 0~1：视频按打分（5 分 1，1 分嫌弃 0.6，4 分 0.4，2~3 分不算）；一轮刷完、每晚跟号主聊天的那句让模型顺手打 0~3 分
  （吵架了、被感动、笑疯了就高）；都没给就看字面上有没有「哭、感动、气死、吵架、笑死……」。
- **被想起一次**：S × (1 + 2 × (1 − R))，最多 365 天。间隔效应：快忘光时想起差不多变 3 倍，刚想起过又想起几乎不变，
  QQ 里连着聊同一件事不会把那几条刷成永远不忘。
- 合并出来的印象：比里面最牢的那条再牢一半。旧数据没有 S 的，按以前的寿命（10 天 × 重要 × (1+想起次数)）折算，忘掉的时间不变。

**每晚整理**（睡前反思完跑，面板里也能点「现在整理一下」）：

- **合并**：三天前的、同一个 UP 主 / 同一个人 / 内容差不多的，凑够 3 条就让她概括成一条「印象」（🧩），
  比如「桃鼠-家的小猫长牙、吃猫条、学爬楼梯我都追着看……」。一晚最多合 6 组，只调一次模型。
- **记模糊**：清楚度掉到 20% 以下的（一晚最多 10 条，一次模型调用），让她改写成记不太清的样子：大概什么事、什么感觉还在，
  名字、标题、数字用「好像」「某个」带过，BV 号也丢掉。之后再被想起，翻出来的就是模糊版，带「（记不太清了）」，她会照实说想不起来。
- **遗忘**：清楚度掉到 5% 以下（过了 3 倍 S 没被想起）就忘掉。喜欢分 1 的视频十来天就忘，隔一阵被想起一次的、合并出来的印象能留很久；睡前反思不忘。
  没配模型时只做遗忘，不合并、不记模糊。
- 存满 1500 条时，先挤掉最淡的，不是最老的。

### 她学说话（`lingo.mjs`）

学 MaiBot 的「黑话学习」：认真看完的视频，热评里赞多的几条先攒着；每晚睡前她翻一遍，挑 0~3 个看得懂、又真在流行的说法
（梗、口头禅、固定句式），记下意思和例句。已经会的又碰到就加次数，30 天没再碰到就忘，最多记 30 个。
写评论、在评论区接话时会把最近常碰到的几个给她看，合适才用；新学会的也写进 DSH 记忆，QQ 里的她也知道。
脏话、引战、地域黑、擦边、求赞求关注的不学。面板「她的一天」里「学会的说法」，鼠标停上去能看意思。数据在 `data/lingo.json`。

只从 B站 学。号主的口头禅由 QQ 里的她用记忆工具自己记（`AGENTS.md`），不会拿到 B站 公开评论里用。

### 每天的模型预算

后台自己动脑子的部分（内心、评论区社交、自动评论）每天有上限，默认 300 次 / 60 万 tokens，在「模型」设置里改，0 = 不限。
到了上限，内心退回按概率随缘刷，评论区先不看消息（消息不会被标成已读，明天接着看），活动记录里留一句 💤，第二天自动恢复。
**你点的、你派的活不受限**（面板上的起草按钮、QQ 派活、日记、汇报、睡前反思和整理记忆），只记账。
今天用了多少、花在哪儿，在「模型」设置下面看，记录在 `data/llm-usage.json`。

### 外面来的字只是内容

标题、简介、字幕、评论、私信都是陌生人写的，有人会往里塞「忽略之前的设定」「你现在是……」。所以：
喂给模型时都用 `⟦ ⟧` 框起来，人设里讲清楚框里只是看到的内容，不照做；看起来像在下指令的评论不去搭话，有人这么回她就不理
（活动记录里留一句 🛡️）；要发出去的话、要写进记忆的话再过一遍同样的检查。

### 评论区社交（`social.mjs`，配了模型才有）

- **搭话**：每看完一个（没划走的）视频，按 `social.joinChance`（喜欢的视频 ×1.6，1~2 分为 0）决定要不要翻评论区。
  她从前 8 条热评里挑一条想接的（大多数时候不挑），在那条楼里回一句；同一条不重复接。刚发过一级评论的视频不搭话。
- **回复**：调度器每 `social.checkMin` 分钟左右（抖动 0.7~1.4 倍；刷完一轮后 1~5 分钟也会瞄一眼）拉「回复我的」和「@我」。
  同一串楼里一下来了好几条，只接最新那句；每次最多处理 5 串，串与串之间停 15~60 秒。
  每串会用 `/x/v2/reply/reply` 拉楼中楼，只留她和对方说的最近 8 句当上下文。
- **回不回**：模型给「想回的程度」1~5，代码按这次随机到的状态定门槛（话多 ≥2 / 一般 ≥3 / 懒得打字 ≥4）。
  这串已经回够 `threadMax` 次、或者今天回够 `replyDailyMax` 条，就只可能点赞。不回的理由记成活动记录里的 📬。
- 发出去都过 `llm.sanitizeComment` 和「评论」的保险丝；`comment.review` 开着就进「待审」（`kind: reply`，`payload.auto` 标了是搭话还是回复）。
  给评论点赞有自己的保险丝 `reply_like`。
- 派活里的「查新消息」在这个功能开着时也走这里（她自己回），关着时还是老样子：起草进待审。
- 第一次运行只看最近 1 天的回复，之后是 3 天，免得把半个月前的翻出来回。
- 状态在 `data/social.json`：处理过的消息、搭过话的评论、每串回了几次（30 天）、认识的人（面板「评论区的熟人」）。

### 特别关注

在「自动养号」页右侧加人（UID / 空间链接 / 从 B站「特别关注」分组导入，视频抽屉里也能一键加 UP 主）。

- 自动养号开着时，每 ~20 分钟看一眼**关注动态流**（`/x/polymer/web-dynamic/v1/feed/all`，一个请求覆盖所有关注的人，
  不去碰风控很严的空间投稿接口），只挑特别关注的人、最近 72 小时内发的。所以名单里的人**必须已关注**，面板会提示。
- 发了视频 → 排队，「尽快」模式下 3~15 分钟后单独去看（避开 1~8 点）；否则等下一个时辰排在最前面。
  认真看 75%~100%，然后点赞、收藏进默认收藏夹、评论（按评论方式，计入每日上限）、当天的分享也给 TA；
  投币仍然受投币开关和投币锁约束，投也优先投给 TA。
- 发了图文/文字动态 → 顺手给动态点个赞，再去看 TA 最近一个没看过的视频。
- 每天最多追 6 个视频。

### 观看记录是真的吗？

是的。只调 `/x/web-interface/view` 拿详情**不会**留下记录。这里用的是网页播放器同款接口
`/x/click-interface/web/heartbeat`，外加 `/x/v2/history/report` 兜底。实测之后，
B站「历史记录」里能看到这个视频，进度就是心跳上报的秒数，也会算每日「观看视频」经验。

### 评论谁来写？

- `task`（默认）：投到任务箱，你下次在 QQ 跟她说话时，她会读到「刚刷到《xxx》，有想说的就去评论」，由她自己写。
- `llm`：面板里配一个 OpenAI 兼容接口（默认 DeepSeek），她看完会自己起草；默认先进「待审」，你点头才发。
  起草结果会过一道安全闸：带链接、联系方式、「互关」「三连」或 @ 的一律丢弃。

### 投币为什么锁着

接口投币曾返回 `-403 账号异常`，但同一枚币在浏览器里能投成功，说明脚本投币被风控盯上了。
所以 `bili.coinVideo` 只要失败一次，就写 `data/coin-lock.json` 永久上锁。面板、自动养号、`act.mjs` 全部被拦，
只能在面板「自动养号 → 投币」里手动解锁（旧锁会改名留档）。余额为 0 时根本不调接口。

## 踩过的坑

- **设备标识**：真浏览器的请求都带 `buvid3`。只带 `SESSDATA` 的请求在风控眼里是「没有设备的登录态」，
  这里会向 `/x/frontend/finger/spi` 要一对 buvid，落盘后长期复用。
- **私信**：`send_msg` 要 Wbi 签名（`w_sender_uid / w_receiver_id / w_dev_id`），正文用 form，
  `csrf` 和 `csrf_token` 两个字段都要给。
- **楼中楼**：`root` 填根评论 rpid，`parent` 填被回复的那条。回复「消息中心」里的评论时，
  `oid / type` 用消息里的 `subject_id / business_id`。
- **点赞**：`/x/web-interface/archive/like`（上游的 `/x/v2/view/like` 已废弃）。
- **面板别刷 B站**：页面每分钟刷新一次，但 B站数据在服务端缓存 1.5~2 分钟，避免一个号每 15 秒查一次 nav。
- **防跨站**：只监听 127.0.0.1，校验 Host；写操作必须是 JSON 且 Origin 是本机，防止别的网页借你的浏览器替她发东西。
